# Laboratory-VI

Design and evaluation of a proton shielding system for oral cancer irradiation using PHITS Monte Carlo simulations.

## Project Description

This project focuses on the simulation and analysis of proton irradiation in a biological model relevant to oral cancer treatment. Using the PHITS Monte Carlo code, we model particle transport and interactions to evaluate the effectiveness of different shielding configurations.

The goal is to understand how proton beams deposit energy in tissue and how shielding materials can be optimized to protect surrounding healthy regions while maintaining an effective dose in the target area.
